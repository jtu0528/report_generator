# 校務部工作月報產生系統（Report Generator）

自動整合三份 Excel 統計檔，一鍵產出「校務部工作月報告」PDF 的內部系統。

## 專案背景

行政人員每個月都要從多份 Excel 統計檔中手動抓取數字、計算流失率、整理歷年資料，再排版成月報，流程繁瑣又容易出錯。

本專案將這段流程自動化：只要上傳三份 Excel、輸入月份，系統就會自動解析、計算並產出排版完成的 PDF 月報，大幅節省行政作業時間。

## 運作流程

```
上傳 3 份 Excel + 輸入月份
        │
        ▼
  解析 Excel（Apache POI）
        │
        ▼
  整合資料、自動計算
        │
        ▼
  套用月報範本（Thymeleaf）
        │
        ▼
  輸出 PDF（OpenHTMLtoPDF）
```

## 輸入資料

| 檔案 | 提供的內容 |
|------|-----------|
| 綜合統計明細檔 | 學生流失名冊、學生總數、班級數、平均人數、各班型人數 |
| 招生人數檔 | 每月招生人數、國高中人數、小六人數 |
| 歷年統計檔 | 110～115 年各月月底人數、班數、班平均 |

## 功能特色

- **三檔自動整合**：三份不同格式的 Excel 合併成一份完整月報
- **動態欄位定位**：自動掃描表頭找出欄位位置，班級代號或欄位順序變動時不需修改程式
- **自動計算**：班型人數加總、流失率、班平均補算
- **資料防呆**：自動過濾空白列、標題列，以及未填寫或填「無」的專案項目
- **錯誤提示**：找不到工作表、檔案過大等狀況，會以中文說明錯誤原因

## 使用情境

本系統為公司內部的地端（On-premise）系統，與另一套內部系統共同部署在同一台伺服器電腦上。

```
┌─────────────────────────┐        公司內網        ┌──────────────────┐
│  伺服器電腦               │ ◄──────────────────── │  同仁電腦          │
│  ・月報產生系統（本專案）   │  http://伺服器IP:Port  │  瀏覽器開啟 URL    │
│  ・其他內部系統            │                        │  上傳 Excel、下載 PDF│
└─────────────────────────┘                        └──────────────────┘
```

- **開機自動啟動**：伺服器電腦每日開關機，透過 Windows 工作排程器設定「開機時」以系統帳號執行，不需登入或手動啟動
- **內網連線使用**：公司同仁在自己的電腦上以瀏覽器連線伺服器 IP，即可上傳檔案並下載月報，不需安裝任何軟體

## 技術架構

| 項目 | 使用技術 |
|------|----------|
| 後端框架 | Spring Boot |
| Excel 解析 | Apache POI |
| 範本引擎 | Thymeleaf |
| PDF 轉檔 | OpenHTMLtoPDF |
| 建置工具 | Maven |
