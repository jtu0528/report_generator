📄 校務部工作月報產生系統 (Report Generator)

🔗 系統連線 (Internal Access): 於公司內網瀏覽器輸入 `http://<伺服器IP>:<Port>` 即可無縫使用
⚠️ 溫馨提醒： 本專案為地端 (On-premise) 部署，為確保學生與營業資料安全，系統未開放外部網路連線。伺服器已設定開機自動於背景常駐執行，無需人工登入啟動！

📌 專案簡介
本系統專為校務部行政流程打造，旨在解決每月手動整理多份 Excel 統計檔的繁瑣痛點。透過一鍵上傳與自動化邏輯，將原本耗時的資料抓取、流失率計算與歷年數據比對，瞬間轉化為排版精美的 PDF 月報，大幅提升行政效率並消彌人為計算錯誤。

🛠️ 技術架構與部署策略
- 開發框架： 核心後端採用 Java Spring Boot 構建穩定的 API 與服務層。
- 檔案解析與渲染：
  - Excel 萃取： 採用 Apache POI 處理多格式、多工作表的複雜 Excel 檔案。
  - PDF 產出： 結合 Thymeleaf 模板引擎動態填入數據，並透過 OpenHTMLtoPDF 轉換為高質感 PDF 文件。
- 地端部署與零安裝 (Zero-Install)：
  - 將系統打包為獨立 `.jar` 執行檔，直接部署於內部 Windows 伺服器。
  - 同仁無須於個人電腦安裝任何軟體或環境，只要連上公司區網開啟瀏覽器即可直接操作，極大化降低跨機台的教學與維護成本。

📊 系統功能亮點
- 三檔跨維度整合： 一鍵將「綜合統計明細檔」、「招生人數檔」及「歷年統計檔」三份不同結構的報表進行資料清洗與完美合併。
- 動態欄位定位 (Dynamic Mapping)： 系統會自動掃描 Excel 表頭尋找對應欄位，未來即便班級代號新增或欄位順序調換，也完全不需要修改程式碼。
- 智慧防呆與自動補算：
  - 自動略過空白列、標題列及標註為「無」的無效項目。
  - 系統於背景自動補算各班型總數、學生流失率與班平均，確保最終報表數字精確無誤。
- 友善中文錯誤追蹤： 當發生「找不到特定工作表」、「檔案格式錯誤」或「資料過大」時，系統會攔截例外並拋出直觀的中文提示，方便行政人員第一時間排除問題。

🎥 核心運作流程 (Workflow)
- Step 1. 檔案匯入： 透過網頁介面上傳 3 份 Excel 檔並指定產出月份。
- Step 2. 核心解析： Apache POI 定位欄位並萃取所有關鍵數據。
- Step 3. 數據聚合： 執行防呆過濾、業務邏輯計算與歷年資料整併。
- Step 4. 渲染下載： Thymeleaf 套入月報排版，轉化為 PDF 供使用者直接下載。
